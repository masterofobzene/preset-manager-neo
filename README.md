---

## 📦 Installation

1. Open Forge Neo and go to **Extensions**
2. Click **Install from URL**
3. Paste:

```text
https://github.com/masterofobzene/preset-manager-neo
```

4. Click **Install** and reload the WebUI

> ⚠️ This extension is for **Forge Neo** only.
